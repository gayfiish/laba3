## Выполненные задания

### Средней сложности

1. **№6 — Класс со статическим методом**

Реализован класс `MathUtils` со статическим методом `is_even()`, который определяет, является ли переданное число чётным.

Файл: `math_utils.py`

2. **№8 — Класс-счётчик**

Реализован класс `Counter`, который позволяет увеличивать и уменьшать значение счётчика.

Методы класса:
- `increment()` — увеличение значения;
- `decrement()` — уменьшение значения;
- `show()` — получение текущего значения;
- `reset()` — сброс значения счётчика.

Файл: `counter.py`

3. **№2 — Класс «Студент»**

Реализован класс `Student` с полями имени, группы и возраста.

Метод `show_info()` используется для вывода информации о студенте.

Файл: `student.py`

### Повышенной сложности

4. **№4 — Паттерн Strategy для расчёта цены**

Реализован паттерн проектирования Strategy.

Созданы стратегии:
- `RegularPrice` — обычная цена;
- `DiscountPrice` — цена со скидкой.

Класс `PriceCalculator` позволяет менять стратегию расчёта цены во время выполнения программы.

Файл: `price_strategy.py`

5. **№10 — Unit-тесты классов (TDD)**

Для классов реализованы модульные тесты с помощью встроенного модуля `unittest`.

При выполнении задания использован подход TDD:

1. **RED** — сначала был написан тест для метода `reset()`, которого ещё не существовало. Тест завершался ошибкой.
2. **GREEN** — затем был реализован метод `reset()`, после чего все тесты успешно прошли.

Этапы TDD также зафиксированы отдельными коммитами в истории Git.

Файл с тестами: `test_classes.py`
